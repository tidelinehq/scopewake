# Vendor AI catalogue

The catalogue (`scopewake/data/saas_ai_catalogue.json`) is generated by `tools/build_catalogue.py`. Edit the builder, not the JSON.

## Evidence rule

- A fact (on by default, trains on customer data, model providers named, admin can disable) is filled only when it was read from the vendor's own documentation. Each filled fact carries the source URL and the check date.
- Anything not checked stays `"unverified"`. Notes may record a lead from a non-documentation source (for example, a vendor community answer). The note must say so, and the fact stays unverified.
- Domains and product names are matching configuration, not claims about AI behaviour.
- MAS para 4.4 itself names "inadequate disclosure of AI embedded in third-party services". The catalogue is credible only if it never fills a gap with a guess.

## Monthly re-check (para 4.3: review as AI is introduced into existing third-party services)

1. Copy the current JSON to `old.json`.
2. Re-check the facts in the builder against the vendor pages. Add new AI features and new products, then bump `VERSION` and `CHECKED`.
3. Run `python tools/build_catalogue.py`.
4. Run `scopewake catalogue-diff old.json scopewake/data/saas_ai_catalogue.json > docs/catalogue-changes/<version>.json`.
5. Reports flag any entry checked more than 45 days ago.
