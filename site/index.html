Questions

    
Before you run it.

    

      
secrets
It reads configuration files to learn that a credential exists, what kind it is and where it lives. Known secret shapes are redacted from every output format, and tests plant synthetic secrets to check this. Redaction is pattern-based, so an unusual format placed in a name or path could slip through; the docs say so.

      
network
No. A scan opens no network connection and writes no files. A test fails the build if that changes. Installing the package from PyPI uses the network, as any install does.

      
agents
Claude Code, Cursor, Windsurf, VS Code MCP, Claude Desktop, Gemini CLI, Codex CLI and GitHub Actions agent workflows. Cloud connectors for AWS, GitHub and Google Workspace permissions are in development.

      
trifecta
An agent that reads untrusted input, can reach private data and has a way to send data out. Tideline flags it as potential, because config files show what is reachable, not what an agent will actually do.

      
status
It is a pre-release built by a solo founder in Singapore. The scanner works and is tested; it has not yet been run across many real machines. Issues and detection requests are welcome.
